# Pure Drop

**Pure water. Zero waste.**

Pure Drop is a startup concept for a reusable, eco-friendly stainless steel water bottle with a soft silicone base and a carry loop, available in three sizes (350 ml, 500 ml and 750 ml). This repository contains the full launch package: logo, social media posts, infographic, captions, client proposal, cold emails and a single-page website.

## Run the website locally

Download or clone the repository and open `index.html` in any browser. No build step is needed.

## Publish on GitHub Pages

1. Go to **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then click **Save**.
4. The site will be live after about a minute at the link above.
